# Casing Mode: Diesel 3.0 Edition

Brings PAYDAY 3-style casing freedom to PAYDAY 2. Updated for Diesel 3.0 (64-bit).

## What it does

**Mask-off / casing mode**
- Free movement (sprint/crouch/jump) and interactions, no more warning spam.
- Ability-type gadgets (e.g. Pocket ECM) usable; weapons stay blocked.

**Civilian disguise**
- Same movement/interaction freedom and hint suppression as casing mode (including skill interactions like camera loop).
- Weapons and equipment/gadget deployment stay locked until you reach casing mode.

## Requirements
- SuperBLT (64-bit build)
- BeardLib (required for multiplayer sessions)
